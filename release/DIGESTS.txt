## Reproducibility

**Both artifacts are bit-reproducible.** The digests above were confirmed
identical across three builds: twice from the working tree and once from a
fresh clone of the merged `main`, on the same Python.

Check it yourself:

```bash
git clone https://github.com/boxofrecycling/babel-context-integrity
cd babel-context-integrity && git checkout v0.2.0
python -m venv .venv && ./.venv/bin/pip install build
./.venv/bin/python -m build && shasum -a 256 dist/*
```

`release/DIGESTS.txt` is excluded from the sdist — confirmed again for this
release by listing the archive. An archive cannot contain its own hash.
