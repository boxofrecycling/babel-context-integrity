## Reproducibility

**Both artifacts are bit-reproducible.** Rebuilding from a fresh clone
of this repository, on the same Python, produces byte-identical files.
The digests above were confirmed identical across three independent
builds: twice locally and once from a clean public clone.

Check it yourself:

```bash
git clone https://github.com/boxofrecycling/babel-context-integrity
cd babel-context-integrity && git checkout v0.1.0
python -m venv .venv && ./.venv/bin/pip install build
./.venv/bin/python -m build && shasum -a 256 dist/*
```

`release/DIGESTS.txt` is excluded from the sdist. An archive cannot
contain its own hash, and the attempt is what made an earlier build
appear non-reproducible.
