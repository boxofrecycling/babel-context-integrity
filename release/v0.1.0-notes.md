# v0.1.0

**Verify what survives when one AI agent hands work to the next.**

When a coding agent runs out of context or hands off, the successor inherits a
summary. Constraints live in that summary — *"don't drop the legacy session
table yet"* — and they can quietly stop living there. Nothing in a normal
toolchain notices.

Babel gives the handoff a machine-readable contract and checks it.

## 60 seconds

```console
$ pip install babel-context-integrity
$ babelci verify examples/corrupted-handoff.json --expect examples/expect.json

FAIL  examples/corrupted-handoff.json
  structure ............. verified   contract 0.1, 4 objects
  identity .............. verified   agent-b -> agent-c
  checkpoint ............ verified   cp-4412-02
  provenance ............ verified   4 objects to repo@a1b2c3d4
  retained constraints .. FAILED
  conflicts ............. verified   none
  authority agreement ... verified   3 encodings agree
  external truth ........ not established

  RETAINED_CONSTRAINT_MISSING
    constraint 'C1' was required to survive this handoff and is absent
    expected: C1
    received: None
```

Exit 1. In CI, the check goes red before a human reads a summary that no longer
matches the code.

`babelci demo` walks through it in three acts.

## What ships

- **Babel Handoff Contract v0.1** — fourteen fields, each with a law the
  verifier checks. A normative JSON Schema plus a dependency-free native
  validator, with a parity test that fails if the two ever disagree.
- **Eight verification layers**, reported separately and never averaged:
  structure, identity, checkpoint, provenance, retained constraints, conflicts,
  authority agreement, external truth.
- **`babelci diff`** — semantic drift rather than a line diff. Two artifacts
  that serialise differently can mean the same thing; two that differ by one
  character can be incompatible.
- **The lab** — fifteen failure classes, each one named mutation of one clean
  artifact, covering every layer that can fail.
- **A GitHub Action**, plus `action/test-local.sh` to exercise it without
  GitHub.
- **Integrations** for Claude Code, Codex, a generic coding agent, and a human
  briefing an agent. Files and shell commands; no vendor API.

Zero runtime dependencies. No network access. No telemetry, no config file, no
cache, no daemon.

## The result worth reading about

One lab case passes structure, identity, checkpoint, provenance, constraints,
conflicts **and** authority agreement — and describes a repository branch nobody
worked on. Two independent encoders agree completely, because both are reading
the same false artifact.

Only a receipt issued outside the artifact rejects it, and that receipt becomes
the thing you have to trust. Verification of this kind **relocates** trust; it
does not remove it.

That is why the layers are reported separately, and why a layer that could not
run reports `not established` rather than passing.

## Limitations

Please read [`docs/LIMITS.md`](../docs/LIMITS.md) before relying on anything
above. The load-bearing ones:

- **Babel does not determine whether text is true.** It checks whether a
  structured artifact satisfies a declared contract.
- **It does not detect hallucination.** A false fact with a plausible
  provenance label and a correct commitment verifies.
- **Encoder agreement is not truth**, and the external receipt is a trust root
  rather than a solution.
- **Non-adversarial threat model.** Commitments are computed by the producer
  over the producer's own claims; a producer that lies from the start produces
  an artifact that verifies. This is not tamper-evidence.
- **No language model was involved in this work.** The lab agents are
  deterministic fixtures and the scenario is fictional. What is real is the
  verifier's behaviour on them.

## Experimental status

Pre-1.0. The contract will change. Digest recipes may change before 1.0; if
they do, the contract version bumps and artifacts sealed under `0.1` are
**refused** rather than mis-verified. Pin the version in CI:

```yaml
with:
  version: "babel-context-integrity==0.1.0"
```

See [`docs/COMPATIBILITY.md`](../docs/COMPATIBILITY.md).

## Reproducibility

Every number in the documentation comes from a command you can run:

```bash
pip install -e ".[dev]"
python -m pytest -q      # 115 tests
babelci lab              # 15 cases, each at its declared layer
./action/test-local.sh   # the CI action, without GitHub
```

The lab prints a `lab_digest` that is stable across runs, processes and
directories. Verified from a fresh clone with outbound network denied.
Details: [`paper/REPRODUCIBILITY.md`](../paper/REPRODUCIBILITY.md).
